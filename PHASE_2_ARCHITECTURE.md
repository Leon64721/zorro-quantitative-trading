## 🔧 COMPONENTE 1: STRATEGY GENERATOR (RAG)

**Responsabilidad**: Generar estrategias válidas basadas en el grafo

### Flujo:
1. **Entrada**: Descripción en lenguaje natural
   ```
   "Crear estrategia que compre cuando SMA rápida cruza arriba 
    de SMA lenta y venda cuando RSI > 70"
   ```

2. **Procesamiento**:
   - Parse de requisitos (indicadores, condiciones)
   - Búsqueda en grafo: encontrar nodos relacionados
   - Extracción de corpus: patrones similares
   - Selección de template base

3. **Generación**:
   - Rellenar template con parámetros
   - Agregar gestión de riesgo (Stop, TP)
   - Incluir validaciones

4. **Salida**: Código Lite-C compilable

### Ejemplo de Salida:
```c
// AUTO-GENERATED by ZORRO Strategy Generator
// Date: 2026-09-14
// Description: SMA Crossover with RSI Confirmation

function run()
{
    // Configuration
    BarPeriod = 5;
    StartDate = 20200101;
    EndDate = 20261231;
    asset("ES");
    LookBack = 100;
    
    set(PLOTNOW|LOGFILE);
    
    // Series
    vars Close = series(priceClose());
    
    // Indicators (from graph knowledge)
    var sma_fast = SMA(Close, 10);   // Fast MA
    var sma_slow = SMA(Close, 20);   // Slow MA
    var rsi = RSI(Close, 14);         // RSI confirmation
    
    // Risk Management
    Stop = 2 * ATR(14);
    TakeProfit = 3 * ATR(14);
    Lots = 1;
    
    // Entry Logic
    if(crossOver(sma_fast, sma_slow) && rsi < 70 && !NumOpenLong)
    {
        enterLong();
        printf("\nEntry: SMA crossover at %.4f, RSI: %.0f", price(), rsi);
    }
    
    // Exit Logic
    if(NumOpenLong > 0 && rsi > 70)
    {
        exitLong();
        printf("\nExit: RSI overbought");
    }
}
```

## ✅ COMPONENTE 2: ZORRO VALIDATOR

**Responsabilidad**: Garantizar 100% compatibilidad

### Validaciones:
- **Sintaxis Lite-C**: Paréntesis, tipos, funciones
- **Indicadores válidos**: Solo usar SMA, EMA, RSI, ATR, etc.
- **Funciones de entrada/salida**: enterLong(), exitShort(), etc.
- **Variables globales**: BarPeriod, asset, LookBack, etc.
- **Gestión de riesgo**: Stop y TakeProfit antes de entry

### Reglas (de graph.json):
```json
{
  "valid_indicators": [
    "SMA", "EMA", "WMA", "ATR", "RSI", "ROC", "MACD",
    "BBands", "Stochastic", "CCI", "Momentum"
  ],
  "entry_functions": ["enterLong", "enterShort"],
  "exit_functions": ["exitLong", "exitShort"],
  "required_config": ["BarPeriod", "asset", "StartDate", "EndDate"],
  "risk_params": ["Stop", "TakeProfit", "Lots"]
}
```

## 🧪 COMPONENTE 3: BACKTEST RUNNER

**Responsabilidad**: Ejecutar y medir estrategias

### Flujo:
1. **Guardar** código en: `D:\ZORRO\Strategy\GENERATED_STRATEGY.c`
2. **Ejecutar** ZORRO (via CLI o API)
3. **Capturar** resultados del backtest
4. **Extraer** métricas:
   - Total trades
   - Win rate %
   - Profit factor
   - Sharpe ratio
   - Max drawdown
   - Return %

### Métricas de Éxito:
```
✅ BUENO:
- Win Rate: > 40%
- Profit Factor: > 1.5
- Sharpe: > 0.5
- Max Drawdown: < 25%

❌ MALO:
- Win Rate: < 30%
- Profit Factor: < 1.0
- Sharpe: < 0.2
- Max Drawdown: > 40%
```

## 🎯 COMPONENTE 4: OPTIMIZER

**Responsabilidad**: Mejorar estrategias iterativamente

### Ciclo de Mejora:
```
1. Estrategia Base (Random)
   ↓
2. Backtest 1
   ↓
3. Analizar Resultados
   ↓
4. Ajustar Parámetros
   - SMA periods: 5 → 50
   - RSI threshold: 20 → 80
   - Risk ratio: 1:2 → 1:4
   ↓
5. Backtest 2
   ↓
6. Comparar (mejor que antes?)
   ↓
7. Si mejora: guardar y repetir
8. Si no mejora: otro ajuste
```

### Técnicas:
- **Grid Search**: Probar combinaciones de parámetros
- **Monte Carlo**: Validar robustez
- **Walk Forward**: Evitar overfitting
- **Genetic Algorithm**: Evolucionar parámetros
