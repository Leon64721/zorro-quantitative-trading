continue

Jumps to the begin of a while loop or the continuation part of a for loop.

Example:

int x = 0;
int y = 0;
while (x < 100)
{ 
 	x+=1;
 	if(x % 2) // only odd numbers
 	  continue; // loop continuing from the start
 	y += x; // all odd numbers up to 100 will be sum
}
