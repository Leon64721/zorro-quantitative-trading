quit (string Text): int

Terminates or aborts the session or simulation cycle, and prints the text to the message window.

Returns

1 if Text begins with '!' or '#', otherwise 0.

Remarks:

  • A quit call does not return immediately from the current run function, which will continue until the end. For returning immediately from a function, place a return statement before quit() (see example).
  • If Text begins with '!', the session or simulation will abort without EXITRUN and end statistics, as if [Stop] was pressed. No further cycles will be excecuted.
  • If Text begins with '+', the session or simulation will restart from the first bar on.
  • Otherwise the current session or simulation cycle will prematurely end, the EXITRUN flag will be set, open trades closed, statistics calculated, and the simulation will then proceed to the next training or simulation cycle, if any. At the end of all cycles, the simulation stops and Text is printed to the message window.

Example:

if(Equity < 100)
  return quit("!Out of money!");
