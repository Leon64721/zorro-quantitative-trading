# fmod

Source: https://zorro-project.com/manual/en/fmod.htm

fmod


## fmod(var x, var y): var

Returns the fractional remainder of **x** divided by **y**,
similar to the integer **%** operator.

### Parameters:

**x** - dividend **
y** - divisor.


### Returns:

Remainder of **x/y**.
### Speed:

Fast

### Example:


```
var x = fmod(1.255,0.250); *// x = 0.005*
```
